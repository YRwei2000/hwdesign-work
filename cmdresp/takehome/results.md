# Float32 2-D max-pooling results — committed specification v2

**Overall: PASS for the corrected implementation.** The original failed interface implementation, first co-simulation and authorized measurement replay remain preserved in [the initial report](results_initial.md). The confirmed prompt and numerical/protocol semantics were not changed. No Git commit or push was performed.

## Interface

The wire encoding is unchanged: [layout.md](layout.md), [serialized examples](evidence/layout_examples.json). Six uint32 input words are `[0x504f4f4c, tx_id, opcode, H, W, K]`; COMPUTE=1 and END=2. The three-word response is `[tx_id, H/K, W/K]`. Headers end with TLAST. Matrix/result words carry one original binary32 sample each, row-major, with TLAST only at the end. END ignores H/W/K, sends nothing and stops the activation.

AXI-Lite contains control and read-only halted/error/tx_id; status is cleared per activation. Codes are 0 success, 1 header, 2 opcode, 3 H range, 4 W range, 5 K range, 6 window bounds, 7 divisibility, 8 early payload TLAST, 9 missing final TLAST. Unavailable tx_id uses 0xffffffff without further reads. Offsets 0x10/0x20/0x30 are retained in [generated control RTL](evidence/fix_v2/synthesis/max_pool_control_s_axi.v).

Both final AXIS interfaces have register_mode=off, verified from actual interface generation messages and absence of the input/output register slices in [RTL](evidence/fix_v2/rtl/max_pool.v): [policy verdict](evidence/fix_v2/interface_policy.json).

## Design

[pool.py](pool.py), [oracle.py](oracle.py), scenario intent and [the kernel body](max_pool_body_impl.tpp) retain their original hashes. The kernel validates headers word by word, then checks parameters in the required order. It writes the complete response, buffers and validates the full matrix, computes/caches row-major strict-greater maxima, then emits the complete result burst. Payload errors return before result emission. No Python timing model or performance-optimization rewrite was introduced.

The first correction attempt put off directives in project Tcl. They were accepted as commands but the generated bare AXIS pragmas left both interfaces at the default both mode: [failed attempt](evidence/fix_v2/tcl_attempt/verdict.json), [actual log](evidence/fix_v2/tcl_attempt/vitis_synth.log). The minimal effective fix is [generate_fix.py](generate_fix.py): a project-local Waveflow signature-emitter configuration adds only the two explicit off options during generation. It does not post-edit generated files or modify the installed Waveflow package. [The generated boundary](gen_off/max_pool.cpp) otherwise matches the original byte for byte after removing those options; headers remain identical. [Generation diff and guards](evidence/fix_v2/generation.json), [effective build log](evidence/fix_v2/off_build.log).

The independent [RTL host](rtl_protocol_tb.sv) loads complete serialized fixtures, advances only on external AXI handshakes, reads status through AXI-Lite and keeps the next unaccepted beat valid through completion, status reads and the observation window. It resets the DUT/stream path before cancelling that beat and loading the next independent activation. A harness watchdog only detects a hung test; it is not an input timeout or hardware error path.
