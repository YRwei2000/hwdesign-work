# Float32 2-D max-pooling results — prompt v2

**Overall: FAIL.** Functional output/status comparisons are PASS; the complete protocol and measurement verdict also includes the RTL waveform checks below.

## Interface

The host contract is in [layout.md](layout.md), with actual Waveflow [serialized examples](evidence/layout_examples.json). All header fields are uint32: input `[magic=0x504f4f4c, tx_id, opcode, H, W, K]`, six words; response `[tx_id, H/K, W/K]`, three words. TLAST ends each header. COMPUTE=1, END=2; END ignores H/W/K and sends nothing. Each payload/result word is one binary32 sample, row-major, with TLAST only on its final word.

Status is cleared per activation. AXI-Lite contains only control and halted/error/tx_id. Error codes: 0 success, 1 header, 2 opcode, 3 H range, 4 W range, 5 K range, 6 window bounds, 7 divisibility, 8 early payload TLAST, 9 missing final TLAST. Unknown tx_id uses 0xffffffff without another read. Actual generated register offsets are 0x10/0x20/0x30 in [control RTL](evidence/synthesis/max_pool_control_s_axi.v).

## Design

[pool.py](pool.py) defines the untimed scalar model and schemas; [oracle.py](oracle.py) independently uses NumPy reshape/max with a first-equal bit gather. Waveflow [generation](generate.py) produces [the boundary](gen/max_pool.cpp) and unedited serializers. [The HLS body](max_pool_body_impl.tpp) reads each header word with immediate framing checks, validates parameters in the specified order, writes the response header, then buffers the complete matrix. After input validation, nested row-major window loops use strict-greater float comparisons, fill the result buffer and emit the complete result burst. Payload errors return before any result emission. Local buffers never authorize state in another command/activation.

The initial implementation pipelines input reception and result emission at II=1; pooling/window and header loops have their actual II reported below. There was one synthesis of this design and no performance-optimization/restructuring iteration. No Python timing model was created. [Source review](evidence/source_review.json) and [C operation traces](evidence/check_c_order.json) distinguish source-level reads from external AXI transfers; only waveform data establishes physical transfer order.

## Verification

The independent model gate passed **516** arithmetic cases and **66** activations, including **29** errors and **29** separate fresh-stream recoveries. Sources: [arithmetic vectors](evidence/arithmetic.json), [model gate](evidence/model_gate.json), [model log](evidence/model_validation.log). The gate preceded the first Vitis attempt; frozen model/intent hashes remain unchanged. The hand example has literal expected binary32 patterns for [[6,8],[14,16]]; negative, signed-zero tie and finite-normal boundary literals accompany deterministic random supported-domain matrices. [Checker rejection evidence](evidence/checker_rejections.json) shows changed data bits, missing TLAST, wrong status, extra reads and fake results rejected.
